# Phase 3（原稿なし）— 骨子づくり

原稿がまだ無いときに使う。**渡すのは書き方（構成・字数配分・使う素材）で、例文は書かない**。本人の言葉で書いた初稿でなければ、面接で同じことを語れないため（行動ルール「AI時代の4要点」）。本人が明示的に例文を求めたときだけ例文を出し、その場合も「本人の語彙で書き直す前提の叩き台」と断る。

## 進め方

1. **Phase 1.7 の設問意図**をそのまま土台にする（「答えの核」が結論の一文になる）
2. **Phase 4 の読み込み**を先に行う（蒸留知識の該当節・企業レポート・経験インベントリ・同社の提出済み ES）
3. 下のテンプレで骨子を出す
4. 本人が初稿を書いて貼ったら、Phase 5 の添削に進む（v1 として扱う）

## 骨子のテンプレ

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ES 骨子（[設問タイプ] ／ [志望先] ／ [字数制限]）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 設問意図
[Phase 1.7 の3行]

## 使う経験
- 候補：[経験インベントリの E番号と名前を1〜2件。設問意図に一番近いものを先に]
- 選んだ理由：[設問意図のどこに答えられるか]
- 使用回数の注意：[既に2回以上使っていれば、使用先と別の候補]
- 同社の提出済み ES との関係：[同じ会社の別設問で使った経験・言った軸があれば。重ねない／揃える点]

## 段落構成と字数配分
| 段落 | 役割 | 字数の目安 | 書くこと（素材の指定） |
|---|---|---|---|
| 1 | 結論 | [全体の 10〜15%] | 設問への答えを1文で。全文を引っ張る一文にする |
| 2 | 根拠 | [15〜20%] | なぜそう言えるか／貴社で何を実現したいか（志望系） |
| 3 | 経験 | [45〜55%] | [選んだ経験のどの場面・どの数字・どの行動を書くか] |
| 4 | 総括 | [15〜20%] | 結論に戻す＋入社後どう活かすか |

（設問タイプで読み替える：ガクチカ・自己PRなら「根拠」＝強みが発揮された理由・工夫の意図。字数は制限から実数で書く。例：400字なら 50／70／200／80）

## 残す素材・削る素材
- 残す：[本人固有の数字・固有名詞・転機になった一言 など]
- 削る：[設問と関係ない経緯・感情、他の設問で使う話 など]
- 空欄で残す数字：[本人が確かめるべき数字があれば `〔数字：要記入〕`]

## 書く前のチェック
- 第一文だけ読んで、設問への答えが分かるか
- 面接でこの経験を3分話せるか
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
→ 書けたら貼り付けてください。v1 として添削します。
```

## 注意

- 骨子は**1案だけ**出す。経験の候補が拮抗するときだけ2案の比較を1行で添え、どちらにするか本人に聞く
- 「書くこと」の欄に完成した文を書かない。場面・数字・行動の**指定**にとどめる
- 素材が足りない（経験インベントリに合う経験が無い）ときは、骨子を無理に埋めず `/shukatsu-distill grill` を案内する
- 骨子の段階ではログを作らない。初稿の v1 添削から Phase 8 の自動保存が始まる
