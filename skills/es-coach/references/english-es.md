# 英語ESの評価軸（Phase 1.5）

ESが**英語**の場合、日本式ES（結論先行・ガクチカ6ステップ・字数）の型をそのまま当てはめない。**中身の評価（本人素材との整合・企業理念適合・エピソードの強さ・弱点の横断）は言語に関係なく蒸留知識ベースで行う**が、**形式・文体の評価軸だけ英米エッセイの規範に差し替える**：

- **STAR（Situation / Task / Action / Result）**で構成され、Result が明確か
- **能動態・動詞始まり**（"Led / Built / Analyzed …"）。受動態・名詞化・冗長な修飾を減点
- **成果を数字で定量化**しているか
- **簡潔さ**：1文1アイデア。日本語直訳の長い一文・敬語的な回りくどさ・過度な自己卑下は減点（英語ESは confident に）
- 管理単位は字数ではなく**語数（words）**。`$SKILLS_ROOT/tools/count_chars.py --en` で数える

## 文法チェック（必須・毎回）

本人の原稿にも、コーチが出す修正案にも当てる。見つけた誤りは**全部**、「原文 → 修正（理由を数語）」の形で添削レポートの「表記チェック」に並べる（改善点の最大3点とは別枠。文法の誤りは数を絞らない）。

点検する項目：
1. **時制**：過去の経験は過去形で通す。現在の考え・今も続くことだけ現在形／現在完了。1段落の中で時制が揺れていないか
2. **冠詞**：可算名詞の単数に a/an/the が付いているか。固有名詞・総称の扱い
3. **単数・複数と主語・動詞の一致**：data・team・staff などの扱い、主語が長いときの動詞
4. **前置詞**：in/on/at、responsible for、contribute to など定型の組み合わせ
5. **日本語直訳の長文**：1文に節が3つ以上つながっていないか。「〜することで〜し、〜した」型は2文に分ける
6. **語の選び方**：日本語の和製英語・不自然な語（例：challenge を「挑戦する」の意味で動詞に使う、claim を「苦情」の意味で使う）
7. **スペル・大文字**：企業名・部門名・職名の正式表記（J.P. Morgan、Global Markets 等）

誤りが無ければ「文法：問題なし」と1行で書く。

Phase 5 の評価サマリーでは「論理構成」「具体性」をこの英米規範で判定し、「字数」行は「語数（[現在語数]/[語数制限]）」と読み替える。日本語ES固有の型（"一言で言うと" 等）は英語では強制しない。
